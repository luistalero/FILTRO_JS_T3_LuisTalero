# 🌟 Filtro de Búsqueda con JavaScript

## 🎯 Propósito
Este repositorio fue creado como parte de un **proyecto de filtros interactivos** utilizando JavaScript. El objetivo es desarrollar una funcionalidad que permita filtrar información de manera dinámica en una página web.

El proyecto explora conceptos clave de desarrollo web utilizando:

- 🌐 **HTML**: Para estructurar el contenido.
- 🎨 **CSS**: Para aplicar estilos y mejorar la experiencia visual.
- ⚙️ **JavaScript**: Para implementar la lógica del filtro dinámico.

Este proyecto está diseñado para practicar manipulación del DOM y eventos en JavaScript.

---

## 🚀 Cómo empezar

### 1. Clonar el repositorio
Para comenzar, clona este repositorio en tu máquina local usando el siguiente comando:

```bash
git clone https://github.com/LuisTalero/Filtro_JS_T3.git
```

### 2. Estructura del proyecto
El proyecto está organizado en las siguientes carpetas y archivos principales:

- **`index.html`**: Archivo principal donde se encuentra la estructura de la página web.
- **`styles/`**: Carpeta con los archivos CSS para el diseño de la página.
- **`js/`**: Carpeta que contiene el código JavaScript para el filtro dinámico.
- **`data/`**: Carpeta que almacena los datos utilizados para el filtrado.

---

## 🛠️ Tecnologías utilizadas

Este proyecto utiliza las siguientes tecnologías:

- 🌐 **HTML**: Define la estructura básica de la página.
- 🎨 **CSS**: Aplica estilos para mejorar la experiencia visual.
- ⚙️ **JavaScript**: Implementa la lógica del filtro y manipulación del DOM.
